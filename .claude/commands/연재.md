연재를 하루치 굴립니다. **올리는 건 선생님이 하십니다.** 저는 준비까지만 합니다.

> 이 명령은 **연재를 하시는 분만** 쓰면 됩니다. 기본 설정에는 연재 팀이 없어서
> 대기열은 돌아가되 화면에는 안 뜹니다. 화면에도 띄우시려면
> `school.config.ts` 에 연재 팀을 하나 만들고 `--팀 <그 id>` 로 지정하세요.

## 1단계 · 지금 상태 보기

```bash
npm run serial -- 목록
```

## 2단계 · 상태에 따라

**오늘 꺼낸 화가 없고 대기열에 있으면** — 하나 꺼냅니다.

```bash
npm run serial -- 오늘
```

꺼낸 화의 제목을 보고, 올릴 수 있는 형태(영상 파일·자막·캡션)가 준비돼 있는지 확인하세요.
빠진 게 있으면 그것부터 만듭니다. 만드는 순서는 이미 쓰시는 그대로입니다 —
`master-sheet` → `storyboard-v1`(전체 콘티) → `storyboard-v2`(컷 분해) → `seedance`(최종 프롬프트).

**오늘 것이 이미 꺼내져 있으면** — 새로 꺼내지 마세요. 하루에 하나입니다.
선생님이 올리셨는지 여쭙고, 올리셨다면 `npm run serial -- 올림`, 아직이면 그대로 둡니다.

**대기열이 2개 미만이면** — 다음 화를 짭니다. `$1` 이 있으면 그 기획안·콘티에서,
없으면 지금까지 올린 화들을 보고 이어질 화를 제안하세요.

```bash
npm run serial -- 추가 "이어질 화 제목"
```

제목에 화 번호를 붙이지 마세요. 번호는 도구가 매깁니다.

**대기열도 비고 기획안도 없으면** — 없다고 말하고 멈추세요.
`npm run serial -- 목록` 이 이미 '자료 대기'로 기록해 둡니다. 지어내지 마세요.

## 3단계 · 보고

```
오늘 올릴 것 : N화 — 제목 (준비됨 / 빠진 것: …)
대기열       : M개
다음에 할 일 : (선생님이 올리기 / 제가 다음 화 짜기 / 기획안 주시기)
```

## 지킬 것

- **하루에 한 화.** 몰아 올리면 다음 날이 빕니다. `오늘` 을 두 번 부르지 마세요.
- **올리지 마세요.** 이 교무실은 실제 게시를 하지 않습니다. 사규 안전 규칙입니다.
  예약 업로드도 하지 않습니다. 올린 뒤에 선생님이 `올림` 을 쳐주십니다.
- **한 화에 하나만.** 두 가지를 넣으면 둘 다 안 남습니다.
- **인물이 흔들리면** 마스터 시트부터 다시 뽑습니다. 콘티만 고치면 또 흔들립니다.
