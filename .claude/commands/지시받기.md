description: 화면(지시창)에서 들어온 지시를 꺼내 실제로 한다. 끝내면 화면에 결과를 돌려준다.
---

화면의 지시창은 일을 못 합니다. 받아 적기까지가 화면 몫이고, 하는 건 여기입니다.

1. `npm run orders` 를 실행해 안 한 지시를 꺼냅니다.
   - 하나도 없으면 "들어온 지시가 없습니다" 라고만 전하고 끝냅니다. 없는 일을 지어내지 마세요.
2. 지시가 여러 건이면 **오래된 것부터 하나씩** 합니다. 한꺼번에 하지 마세요.
3. 지시마다 이 순서를 지킵니다.
   - `TEACHER_OFFICE.md` 의 `## 0. 안전 규칙` 을 먼저 읽습니다.
   - 지시에 팀이 붙어 있으면 그 팀 기준으로 일합니다. `school.config.ts` 의 `DEPARTMENTS` 를 보세요.
   - **무엇을 위한 것인지 한 줄도 없으면 만들기 전에 되묻습니다.** 여기서 지어내면
     화면에는 '마침'이 뜨는데 쓸 수 없는 물건이 남습니다.
   - 일하는 동안 화면에도 그렇게 보이게 합니다.

     ```
     npm run record <팀id> "작업 중" "<지금 하고 있는 일 한 줄>"
     ```
4. 끝나면 **두 군데** 를 적습니다. 하나만 적으면 화면과 기록이 어긋납니다.

   ```
   npm run orders -- 완료 <지시id> "<한 줄로 결과>"
   npm run record <팀id> 마침 "<한 줄로 결과>"
   ```
5. 못 하는 것이면 못 한다고 적습니다. `마침` 이 아니라 `자료 대기` 입니다.

   ```
   npm run record <팀id> "자료 대기" "<무엇이 없어서 못 하는지>"
   ```

## 지킬 것

- **안 한 것을 했다고 적지 않습니다.** 화면의 '마침'은 선생님이 믿는 표시입니다.
- **선생님이 정할 일을 혼자 정하지 않습니다.** 고를 것을 내놓고 묻습니다.
- 결과 한 줄은 **무엇을 했는지**로 적습니다. "완료했습니다"는 아무것도 알려주지 않습니다.
