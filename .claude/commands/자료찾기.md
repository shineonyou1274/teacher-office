`$1` 에 대한 자료를 찾습니다. **순서를 지키세요 — 내 드라이브가 먼저입니다.**

## 0단계 · 팀 id 확인

설정마다 팀 이름이 다릅니다. 기록하기 전에 먼저 봅니다.

```bash
grep '{ id:' school.config.ts
```

여기서 **자료를 찾는 팀**과 **웹을 보는 팀**의 id 를 고르세요.
(기본 설정은 `research` 하나, 예시 설정은 `drive` 와 `websearch` 로 나뉘어 있습니다.)
아래에서 `<자료팀>` `<웹팀>` 이라고 쓴 자리에 그 id 를 넣으면 됩니다.
없는 id 로 적으면 `record.mjs` 가 막고 지금 있는 팀 목록을 알려줍니다.

밖에서 새로 찾기 전에 이미 만들어 둔 것부터 봅니다. 같은 걸 두 번 만들지 않으려는 것입니다.

## 1단계 · 내 드라이브

`gws` 가 깔려 있는지 먼저 확인하세요.

```bash
which gws && gws --help
```

**있으면** — `--help` 에서 드라이브 검색 명령을 확인하고(도구마다 다릅니다),
`$1` 로 검색해서 **파일 이름·수정일·링크**를 가져오세요. 짐작으로 명령을 만들지 말고
`--help` 에 나온 그대로 쓰세요.

찾았으면 기록합니다.

```bash
node scripts/record.mjs <자료팀> 마침 "드라이브에서 N건 — 가장 최근 것: <파일명>"
```

**없거나 안 되면** — 없다고 적습니다. **찾은 척하지 마세요.**

```bash
node scripts/record.mjs <자료팀> "자료 대기" "gws 미설치 — 드라이브를 못 봤습니다"
```

## 2단계 · 웹

드라이브에서 나온 게 없거나 모자랄 때만 웹을 봅니다.
찾으면 **출처 링크를 반드시** 같이 적으세요. 출처 없는 문장은 쓰지 않습니다.

```bash
node scripts/record.mjs <웹팀> 마침 "웹에서 N건 — 출처 확인됨"
```

웹도 막혀 있으면 마찬가지로 `자료 대기` 로 적습니다.

## 3단계 · 선생님께 보고

이렇게 답하세요.

```
드라이브: N건 (있으면 파일명과 수정일)
웹:       N건 (있으면 제목과 출처 링크)
겹치는 것: 드라이브 자료로 대신할 수 있는 웹 자료가 있으면 짚어주세요
빠진 것:   못 찾은 것이 있으면 무엇이 없는지
```

## 지킬 것

- **드라이브를 먼저 봅니다.** 웹부터 뒤지면 이미 있는 걸 또 만듭니다.
- **못 본 것을 봤다고 적지 않습니다.** `gws` 가 없으면 `자료 대기` 입니다.
  이 교무실의 안전 규칙입니다 — 연결 안 된 서비스를 '완료'라고 보고하지 않습니다.
- **파일 내용을 함부로 열지 마세요.** 목록과 제목까지만 보고, 열어야 하면 먼저 물어보세요.
- **학생 실명이 든 파일은 목록에서도 이름을 그대로 적지 마세요.** `3반 관찰기록` 처럼 줄여 적습니다.
